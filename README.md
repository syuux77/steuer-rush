# Steuer-Rush

Messe-Minigame für die Ausbildung in der Steuerberatung (ECOVIS Karriere).

- Läuft komplett im Browser, ohne Anmeldung.
- Nach dem ersten Öffnen offline spielbar (Service Worker).
- Highscore wird lokal auf dem Gerät gespeichert.

## Auf dem iPad einrichten

1. Seite in Safari öffnen.
2. Teilen-Symbol → „Zum Home-Bildschirm“ → „Hinzufügen“.
3. Spiel über das neue Symbol starten (läuft im Vollbild).

Stand-Einstellungen: unten auf der Startseite „Stand-Einstellungen“ 1,5 Sekunden gedrückt halten.
